# Annict 連携

capsicum は [Annict](https://annict.com/) (アニメ視聴記録サービス) と連携し、視聴中・視聴後のアニメに対する実況投稿〜感想記録までを capsicum 内で完結させます。

## なにができるか

- **作品 / エピソード検索**: Annict のデータベースから放送中アニメを検索し、エピソード単位で実況投稿用のタグセット (作品名・話数・サブタイトル・ハッシュタグ) をワンタップで挿入
- **番組表からの直結**: 開発者のサーバー (モロヘイヤ運用サーバー) で整備された番組表が Annict と紐付いており、放送中の作品をリストから選ぶだけで実況投稿の起点を作れる
- **感想・評価の投稿**: 視聴後、capsicum 内で Annict に感想テキスト・評価 (すごい / いいね / ふつう / うーん) を直接記録できる。ブラウザに切り替える必要なし
- **コマンドトゥートとの統合**: モロヘイヤの実況コマンドが提供するハッシュタグ TL リンク / クリップボードコピー等が同じ動線に揃っており、実況〜感想までの体験が一気通貫

## 動作要件

| 要件 | 詳細 |
|---|---|
| Annict アカウント | [Annict](https://annict.com/) のアカウント (無料) |
| モロヘイヤ連携サーバー | サーバーが [mulukhiya-toot-proxy](https://github.com/pooza/mulukhiya-toot-proxy) を運用している必要があります (Annict OAuth client_secret はモロヘイヤが保持する設計)。開発者のサーバーや、モロヘイヤをセルフホストしている Fediverse サーバーで利用できます。Annict 機能だけ単独で使うことはできません |

## 連携手順

1. capsicum を起動し、モロヘイヤ連携のあるサーバーでログイン
2. 投稿フォーム → タグセット bottom sheet → 「エピソードブラウザ」を選択
3. 初回のみ Annict 連携を求められます。「連携する」をタップすると OS デフォルトブラウザで Annict の認可画面が開きます
4. Annict 側で認可 → 表示される認証コードをコピーし、capsicum 側のダイアログにペーストして「連携」
5. 連携完了。以降は同サーバーでログインしている限り再認証不要

## 利用フロー

### 実況中

1. 投稿フォーム → タグセット bottom sheet
2. 番組表に作品が並んでいるならそれを選択 (タグセット YAML が自動挿入)、または「エピソードブラウザ」から Annict 検索 → 作品 → エピソードを選択
3. 投稿本文に作品名 / 話数 / サブタイトル / ハッシュタグが整って入る

### 視聴後の感想投稿

- **番組表エントリから**: タグセット bottom sheet の各番組行の trailing 「Annict に感想投稿」アイコンをタップ
- **エピソードブラウザから**: エピソード行の trailing 「Annict に感想投稿」アイコンをタップ
- どちらの動線でも感想投稿画面が開き、評価 (4 段階・任意) と感想テキスト (任意) を入力して投稿。両方空のままだと「視聴済みフラグだけ立てる」確認ダイアログが出ます

### エア番組と感想投稿

開発者のサーバーで運用されている番組表には「エア番組」(`air: true` フラグ) として登録されたエントリが含まれます。エア番組とは、**TV / 公式動画配信されていない作品を「公式放送中であるかのテイ」で実況するスタイル**を指します。エアギターの「振りをする」と同じ意味合いで、振りをするのは作品の存在ではなく **実況の扱い方** です。

作品自体は実在するため (過去の放送・配信があった作品など)、**Annict にエントリがある限り感想投稿は普通にできます**。むしろエア番組は capsicum 開発者の主要な感想投稿用途です。感想投稿ボタンの表示判定は `air` フラグではなく **`annict_episode_id` の有無のみ**で行います。

`annict_episode_id` が無い番組表エントリ (Annict 未登録のマイナー作品など) には感想投稿ボタンは表示されません。

## 仕組み (概要)

```
┌───────────┐  POST /api/annict/  ┌──────────────┐  GraphQL  ┌──────────────┐
│ capsicum  │ ──── record ──────→ │ mulukhiya    │ ────────→ │ Annict API   │
│           │       (SNS token)   │ (Ruby)       │  (OAuth)  │              │
└───────────┘                     └──────────────┘           └──────────────┘
```

- Annict OAuth の client_secret は **モロヘイヤ側で保管** (capsicum バイナリには含まれない)
- ユーザーごとの Annict access_token もモロヘイヤ側で暗号化保管
- capsicum は SNS の access_token を Bearer auth でモロヘイヤに渡すだけ
- モロヘイヤがその SNS token に紐付く Annict token を解決して Annict GraphQL を呼ぶ

## プラットフォーム別の対応状況

OS 非依存 (HTTP のみで完結) のため、capsicum が動作する全プラットフォーム (iOS / Android / macOS / Linux / Windows) で同じ体験が得られます。OAuth フローは OS デフォルトブラウザ起動経路 ([#382](https://github.com/pooza/capsicum/issues/382)) を採用しており、Bitwarden / 1Password 等のパスワードマネージャも利用可能です。
